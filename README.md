# LAIN — персональный музыкальный плеер

<p align="center">
  <img src="icons/app_icon.png" width="120" alt="LAIN">
</p>

**LAIN** — минималистичный и выразительный музыкальный плеер для Android с оформлением в духе Material 3 Expressive и палитрой Лейн Ивакуры. Слушай музыку из SoundCloud и с устройства, собирай плейлисты, меняй обои и иконку — всё в одном приложении.

Ярлык на рабочем столе называется **レイン**.

## ✨ Возможности

- **Оформление Material 3 Expressive** — тональные поверхности, крупные скругления, «скверкл»-кнопки, выразительная типографика и волновой ползунок перемотки. Палитра — кофейно-кремовая, с акцентом цвета охры. Есть светлая и тёмная темы.
- **Поиск по SoundCloud** — по токену аккаунта. Запросы идут через актуальный `api-v2.soundcloud.com`, потоки воспроизводятся по HLS. Старый API больше не используется.
- **Импорт из профиля SoundCloud** — кнопки «♥ Импорт лайков» и «▤ Плейлисты» в настройках переносят любимые треки и плейлисты твоего аккаунта в медиатеку (с пагинацией до 5 страниц).
- **Локальная музыка** — вкладка «Файлы»: системный выбор MP3/других аудио, метаданные, воспроизведение без интернета.
- **Плеер** — play/pause, предыдущий/следующий трек, перемотка, скорость 0.5×–2× и регулятор громкости с кнопкой отключения звука. Уровень сохраняется между запусками.
- **Повтор и Shuffle** — повтор переключается по циклу «выкл → вся очередь → один трек» с отдельным индикатором; shuffle использует перемешанный набор без повторов и перетасовывает его заново после прослушивания всех треков.
- **Эквалайзер и усиление** — 10-полосный эквалайзер (31 Гц–16 кГц), 6 пресетов, отдельный регулятор баса и усилитель громкости до 3× с компрессором от клиппинга. Настройки сохраняются.
- **Медиатека** — любимые треки, недавние, пользовательские плейлисты. Всё сохраняется на устройстве.
- **Персонализация** — три пресете обоев (можно поставить и на рабочий стол) и три пресете иконки приложения. Иконка меняется по-настоящему — через `activity-alias` подменяется ярлык в лаунчере.
- **Обновления** — авто проверка последнего релиза GitHub (`releases/latest`) с поиском репозитория `lain-player` и кнопкой перехода к релизу.

## 📱 Установка

Готовый APK лежит в **[релизах](https://github.com/webrch/lain-player/releases)** (debug-сборка, ~3,3 МБ). В репозитории бинарник не хранится — только исходный код.

- Открой `LAIN.apk` на телефоне и разреши установку из неизвестных источников.
- Или через `adb`:

```powershell
adb install LAIN.apk
```

Минимальная версия Android — 7.0 (API 24).

## 🔑 Токен SoundCloud

Настройки → SoundCloud → вставь OAuth-токен и нажми «Сохранить и проверить».

Где взять: открой soundcloud.com → `F12` → `Application` → `Local Storage` → домен soundcloud → скопируй значение `oauth_token` (длинный JWT). Можно также получить токен через OAuth2 своего приложения SoundCloud.

Поле **Client ID** необязательно — оно нужно только для прямых запросов из браузерной версии. В Android-приложении запросы идут нативно через OkHttp, поэтому CORS не мешает.

## 🔄 Обновления и GitHub

Репозиторий проекта: **https://github.com/webrch/lain-player**

Приложение ищет репозиторий `lain-player` через GitHub Search API и проверяет `releases/latest`. Если поиск находит чужой репозиторий с таким же именем, укажи точный `owner/repo` в Настройках → Обновления. Для корректной работы опубликуй релиз с тегом вида `v1.1` и приложи APK к релизу.

### Как дать мне доступ к GitHub

У меня нет твоих учётных данных, поэтому репозиторий я создать не могу. Чтобы я мог создавать репозитории и пушить код сам:

1. GitHub → **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token**.
2. Включи область **repo** (полный доступ к репозиториям). При желании ограничь срок действия.
3. Скопируй токен и передай мне в чате **в виде переменной окружения**, а не в тексте README:

```powershell
$env:GH_TOKEN = "ghp_..."
```

После этого я смогу выполнить:

```powershell
gh auth login --with-token
gh repo create lain-player --public --source=. --remote=origin --push
```

Более безопасный вариант — учётная запись GitHub App с доступом только к нужному репозиторию. **Никогда не публикуй токен в коде или в README.**

Локальный git уже инициализирован, история коммитов есть. Если хочешь сделать это вручную:

```powershell
git remote add origin https://github.com/<твой-логин>/lain-player.git
git push -u origin master
```

## 🧩 Исходный код (бонус)

Проект полностью открыт — можно собрать самому или внести изменения.

- `android/` — Android-проект (Kotlin, WebView + JS-мост, OkHttp, HLS.js).
- `player-web/` — та же оболочка в виде PWA.
- `icons/`, `wallpaper/` — исходные ассеты.
- `tools/process_icons.py` — генератор скруглённых иконок, адаптивных слоёв и mipmap.

Сборка: открой `android/` в Android Studio → **Build → Build APK(s)**. Либо из консоли с JDK 17 и Android SDK 35:

```powershell
cd android
.\gradlew.bat assembleDebug
```

Веб-версия:

```powershell
cd player-web
python -m http.server 8080
```

Открой `http://localhost:8080`.
